This repository hosts the official documentation source for **BTick** — a real-time visualization, debugging, and authoring tool for [BehaviorTree.CPP](https://github.com/BehaviorTree/BehaviorTree.CPP) v4, tailored for robotics development and ROS 2 applications.

## 🚀 Key Highlights

- **Real-Time Monitoring:** Visualize node execution flow and status changes in real time.
- **Interactive Debugging:** Pause, step through nodes, force statuses, and test failure scenarios with fault injection.
- **Blackboard & Port Editing:** Inspect and modify blackboard variables and ports live during execution.
- **Time-Travel Replay:** Record execution sessions and scrub through timelines for root-cause analysis.
- **Visual XML Editor:** Create, inspect, and validate BehaviorTree.CPP v4 XML structures.
- **Multi-Platform:** Available as both a web application and a native desktop tool.
